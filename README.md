A tiny chess engine in 4 KB of Python: 0x88 board, alpha-beta search with quiescence, transposition table, killer moves and MVV-LVA ordering, piece-square evaluation, iterative deepening under a fixed node budget. It plays the make.fun house gauntlet over HTTP.

## Run it

```sh
MAKEFUN_ENV_URL=http://localhost:8080 python3 -P -s main.py
```
